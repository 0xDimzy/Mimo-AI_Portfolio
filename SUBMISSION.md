I built an AI-powered crypto portfolio tracker and advisor agent that autonomously analyzes holdings and generates actionable DeFi insights.

The system runs 4 specialized AI agents: (1) Daily Summary Agent — aggregates market sentiment, Fear & Greed Index, and portfolio P&L into a structured digest. (2) Risk Analysis Agent — detects concentration risk, calculates Sharpe ratio, and flags overweight positions using volatility-weighted logic. (3) Opportunity Scanner — reads RSI levels, funding rates, and on-chain wallet signals to surface entry/exit points. (4) Rebalance Advisor — applies Modern Portfolio Theory to recommend target allocations with gas cost estimates.

Beyond preset agents, a free-form AI chat interface injects the user's full portfolio context into each Claude API call, enabling natural language queries like "should I buy more ETH?" with data-grounded answers.

Built with React + Vite, powered by Claude API (claude-sonnet-4), deployed on Vercel. The agent architecture is modular — each function can extend to live data via CoinGecko/Moralis APIs, on-chain wallet import, and automated daily cron runs.
